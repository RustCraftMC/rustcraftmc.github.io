2. 服务说明

2.1 本软件提供什么

CairnLauncher 是一款第三方的 Minecraft 游戏管理工具，目前提供这些功能：

  • Minecraft 账户管理：Microsoft 账户、离线账户和外置登录账户，可以添加多个，并可把账户绑定到某个实例。
  • Microsoft OAuth 身份认证：通过 Microsoft 官方的设备代码流程登录。
  • 游戏版本管理：安装官方发布的版本，以及 Fabric、Quilt、Forge、NeoForge、OptiFine 等加载器。
  • 游戏实例管理：标准布局、版本隔离、独立实例；导入 .mrpack、CurseForge、MultiMC/Prism 整合包，导出 .mrpack；从 PCL2、HMCL 等启动器的目录导入版本和设置。
  • Java 环境管理：检测已安装的 Java，需要时下载 Mojang 官方提供的 Java 运行时。
  • 游戏启动与运行：按设置启动游戏，游戏异常退出时在本机分析日志，并可导出错误报告。
  • 模组和资源包管理：在本地启用或停用，并可从 Modrinth 和 CurseForge 搜索与安装，通过 Modrinth 检查模组更新。
  • 第三方资源下载：从 Mojang 官方服务器以及你启用的镜像下载游戏文件和资源。
  • 插件与扩展：JavaScript 插件和 YAML 小组件、面板。

2.2 本软件目前没有自动更新

本软件没有自动更新功能：它不会自动检查或安装启动器自身的新版本。需要新版本时，请自行从项目网站或项目仓库获取。

2.3 本软件不是什么

本软件仅是第三方的游戏管理工具。它不销售 Minecraft 游戏授权，不提供 Minecraft 账户，不运营游戏服务器，也不代表 Mojang 或 Microsoft。启动器本身不内置、不分发 Minecraft 游戏文件。游戏文件由启动器按你的操作，从 Mojang 官方服务器下载，或在你启用镜像时从第三方镜像下载。本软件不承诺提供代码中不存在的功能。

3.2 你的责任

你对自己使用的游戏账户及其合法性负责。你不得利用本软件冒用他人的账户，也不得以非法方式获取账户授权。通过 Microsoft 账户登录，应当使用 Microsoft 官方的授权流程。

3.3 本软件中的三类账户

  • Microsoft 账户。 通过 Microsoft 官方的设备代码流程登录：你在 Microsoft 的页面输入账号和密码，本软件看不到它们。登录后，本软件向 Minecraft 服务读取该账户的游戏档案。如果读不到档案，登录失败，并提示该账户可能没有购买 Minecraft，或尚未创建游戏档案。本软件只把“Minecraft 服务能否返回该账户的游戏档案”作为判断依据。 它不调用 Microsoft 或 Mojang 的游戏购买权益（entitlement）接口，不区分购买渠道，登录之后也不会持续复核。因此，登录成功只说明该账户存在 Minecraft 的游戏档案，不构成对你游戏授权的认证或担保。
  • 离线账户。 本软件提供的本地游戏身份配置，见 3.7。
  • 外置登录账户。 通过第三方认证服务器（例如 LittleSkin，或你自己填写的 Yggdrasil / authlib-injector 服务器）登录而建立的本地账户记录。它与 Microsoft 账户和 Minecraft 游戏授权无关，认证服务器由第三方运营。

对居住在中国大陆的用户：

  • 建议你使用已经获得 Minecraft: Java Edition 正式游戏许可的 Microsoft 账户登录。
  • 本软件支持代码实际允许的离线账户使用方式：当软件判断你处于中国大陆地区时（见 3.6），不要求先登录 Microsoft 账户，就可以添加离线账户。
  • 你不得把离线账户理解为 Minecraft 正版授权或游戏许可（见 3.7）。

对中国大陆用户，拥有正版账户是建议，不是使用本软件全部功能的前置条件。

3.5 居住在中国大陆以外地区的用户

对居住在中国大陆以外地区的用户，下列内容是使用本软件的条件：

  1. 你必须拥有有效的正版 Minecraft 账户和对应的游戏使用许可；
  2. 在使用离线账户功能之前，你必须先通过 Microsoft 官方授权流程登录你的正版 Minecraft 账户，并完成本软件实际实施的验证，也就是：本软件实现的 Microsoft 设备代码登录成功，并且 Minecraft 服务返回了该账户的游戏档案（见 3.3）；
  3. 只有完成上述验证之后，你才可以新增离线账户。在本软件目前的实现中，新增外置登录账户适用同样的前置条件；
  4. 你应当确保自己的正版游戏授权持续有效，并遵守 Microsoft 和 Mojang 的相关服务条款。

本条是 CairnLauncher 自身的服务使用条件。它不是 Mojang 或 Microsoft 对所有第三方启动器的统一要求，也不是任何国家或地区的法律规定。

3.6 软件如何判断“中国大陆”

本软件用你设备上的系统设置来判断你是否处于中国大陆（不含香港特别行政区、澳门特别行政区和台湾地区）。它不使用 IP 地理位置，也不会询问你的居住地。

  • Windows： 系统时区是 China Standard Time，并且系统的“国家或地区”设置为中国（CN）。
  • Linux 及其他类 Unix 系统： 时区（环境变量 TZ，或 /etc/localtime 所指的路径）包含 Shanghai、Chongqing、Urumqi、PRC 或 China Standard Time 之一，并且语言环境变量（按 LC_ALL、LC_MESSAGES、LANG 的顺序，取第一个已设置的）以 zh_CN 开头。

判断结果只在软件运行时使用，用来决定是否开放添加离线账户等功能，不会被保存或上传。

这种判断依据的是系统设置，不是你的居住地或法律身份，可能与实际情况不一致。例如：居住在中国大陆但系统设置不同，会被当作中国大陆以外；居住在境外但系统设置为中国大陆，会被当作中国大陆；系统设置也可能被修改。

本章规则适用于你的实际居住地，而不是软件的判断结果。你不得为了绕过 3.5 而修改时区、区域或语言设置。如果软件因设置不一致而限制了某项功能，请先用 Microsoft 账户登录。

3.7 离线账户的定义与限制

离线账户是本软件提供的本地游戏身份配置：你输入一个玩家名，本软件据此在本机生成一个离线标识（UUID）。

  • 离线账户不是 Microsoft 账户。
  • 离线账户不提供 Minecraft 游戏许可证。
  • 离线账户不会自动获得正版账户的皮肤、游戏所有权或在线认证权益。本软件可以按你的设置为离线账户显示公开的皮肤，这不表示你拥有该皮肤，也不表示你获得了对应正版账户的任何权益。
  • 离线账户可能无法加入要求正版身份验证的 Minecraft 多人服务器。
  • 你仍须遵守游戏服务器运营者的规则。
  • 本软件不保证离线账户能够访问所有多人游戏服务。

离线账户不构成 Minecraft 游戏授权，也不应被理解为游戏许可。

3.8 已登录账户与离线账户的关系

  • 离线账户是独立的本地记录，与 Microsoft 账户没有绑定关系。
  • 在 3.5 适用的情况下，添加离线账户以本软件的账户列表里已有 Microsoft 类型的账户记录为前提。软件只检查这一点。
  • 之后你移除 Microsoft 账户，不会自动删除已经添加的离线账户，但在重新登录之前，你无法再添加新的离线账户。用离线账户启动游戏时，本软件也不会重新检查你的游戏授权。
  • 这些检查只是技术手段。你保持游戏授权持续有效的义务（3.5 第 4 项）不以软件是否检查为限。
