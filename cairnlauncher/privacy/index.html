CairnLauncher 隐私政策

文档版本：1.0

生效日期：2026-11-06

适用软件：CairnLauncher 及其命令行工具 cairn。本政策依据软件 0.1.0 版本的源代码编写。

English version: PRIVACY.en.md

要点

  • CairnLauncher 没有遥测、使用统计、崩溃报告上传、广告或用户行为追踪功能，也不会向开发者运营的服务器上传你的数据。
  • 你的账户、设置、游戏实例等数据保存在你自己的设备上，默认位于可执行文件旁的 .cairn 文件夹。
  • 登录、下载、搜索资源时，启动器会直接连接 Microsoft、Mojang、Modrinth、CurseForge 以及你启用的镜像等第三方服务。这些请求是为完成你的操作而发出的，数据由对应的第三方处理，不经过开发者。
  • Windows 上保存令牌的 accounts.dat 使用 DPAPI 加密；其他系统上使用由本机信息派生密钥的软件加密，不是系统凭据库。config.json 等其他文件是明文。详见第 2 节。
  • 开发者不持有你的数据，因此无法替你查询、导出或删除。你可以自行删除本地数据，方法见第 5 节。

1. 概述

1.1 本政策说明什么

CairnLauncher（“本软件”）是一款第三方 Minecraft 启动器，由 RustCraftMC Team（“开发者”）开发。本政策说明本软件会在你的设备上保存哪些数据、会连接哪些网络服务，以及你如何管理这些数据。

本政策与《用户协议》（TERMS.md）是两份独立的文件，也与本软件的开源许可证无关。

1.2 隐私设计原则

  • 不设置用户数据上报系统，不设置遥测。
  • 不设置用户行为追踪和广告追踪，不使用第三方统计、分析或崩溃上报组件。对源代码和依赖项的审查没有发现这类组件。
  • 不主动向开发者的服务器上传用户数据。本软件 0.1.0 版的源代码中，没有向开发者运营的服务器发送数据的代码。
  • 用户配置、游戏实例、账户信息等数据原则上保存在用户自己的设备上，由用户的设备管理。
  • 开发者不通过收集用户个人信息盈利。

1.3 联网请求不等于数据上报

本软件需要联网才能完成登录、下载游戏、搜索模组等功能。这些请求是你的操作（或你启用的功能）的直接结果，由你的设备直接发往第三方服务，不经过开发者的服务器。它们不是开发者的数据上报。第 3 节和第 4 节逐项说明请求发往哪里、发送什么。

1.4 本政策不涵盖的内容

  • Minecraft 游戏本身。游戏由 Mojang Studios 和 Microsoft 提供，游戏进程自身的联网和数据处理适用它们的政策。
  • 你安装的模组、资源包和插件，以及它们自行发起的联网。
  • 第三方服务收到数据之后如何处理。
  • 本软件的修改版或衍生版。
  • 仓库中的实验性界面 CairnPhi 使用同一个核心库，但本政策以 CairnLauncher 主程序为准。

1.5 开源许可证

本软件源代码的开源许可证是独立的法律文件，见项目仓库（RustCraftMC/cairn-launcher）中的 LICENSE 文件；本政策不重复其条款。

2. 本地数据存储

2.1 数据保存在哪里

本软件的数据目录（下文写作 <数据目录>）默认是可执行文件所在文件夹下的 .cairn。设置环境变量 CAIRN_HOME 可以改到别处。这是“便携”方式：数据在可执行文件旁，不写入系统盘的用户目录。

这条规则在 Windows、Linux、macOS 上相同。代码没有使用 %APPDATA%、%LOCALAPPDATA%、~/.config、~/Library/Application Support 等系统标准位置保存启动器自己的数据。项目声明支持的平台是 Windows 10 及更新版本。代码中另有面向 Linux 的实现；macOS 没有专门实现，也未声明支持。

游戏目录（.minecraft 等）和启动器数据目录是不同的东西，见下表。

2.3 敏感信息如何保存

  • Windows。 accounts.dat 整个文件由 Windows DPAPI（CryptProtectData）以当前 Windows 用户的身份加密。这样，换一个 Windows 用户，或者把文件拷到另一台电脑，都无法直接读出内容。它的局限是：以你的 Windows 用户身份运行的其他程序同样可以调用 DPAPI 解密，DPAPI 不按应用隔离，启动器也没有额外设置口令或熵值。
  • Linux 及其他非 Windows 系统。 整个文件用 AES-256-GCM 加密。密钥由 /etc/machine-id（或 /var/lib/dbus/machine-id）、环境变量 USER 和 HOME，以及写在源代码里的一个固定字符串，经 SHA-256 派生。没有机器标识文件的系统（例如 macOS）会改用源代码里固定的回退字符串，保护更弱。本软件不使用 macOS 钥匙串、Linux Secret Service（libsecret、GNOME Keyring、KWallet）或其他系统凭据库。能读到机器标识和环境变量的人或程序可以重新算出密钥，所以这种加密只能防止文件被拷走后直接查看，强度低于系统凭据库。
  • 其他文件不加密。 config.json、appearance.json、日志和缓存都是明文。你填写的 CurseForge API Key 或自定义的 Microsoft 应用 ID 就以明文保存在 config.json 中。
  • 游戏运行时。 启动器把访问令牌作为 --accessToken 启动参数交给游戏进程，这是 Minecraft 的标准做法。同一系统上的其他程序有可能看到进程的启动参数。离线账户不使用真实令牌。

2.4 本软件不保存的内容

本软件不保存你的 Microsoft 账户密码：你在 Microsoft 的登录页面里输入账号和密码，启动器看不到。外置登录（Yggdrasil）的密码只用于一次登录请求，不写入磁盘。

登录时，启动器会自动把 Microsoft 给出的一次性设备代码复制到系统剪贴板，方便你粘贴到登录页面。该代码只在短时间内有效，只能用于这一次登录；同一系统上的其他程序可能读到剪贴板里的内容。

3. 第三方服务

3.1 本软件可能直接连接的服务

下表中的“何时连接”区分了你主动触发的操作和自动发生的请求。

服务用途与何时连接发送的内容
Microsoft 身份平台（login.microsoftonline.com）登录 Microsoft 账户（OAuth 设备代码流程）。你点击登录时连接，之后令牌过期会自动刷新应用（客户端）ID、请求的权限范围（XboxLive.signin、offline_access）、设备代码；刷新时发送刷新令牌。你在 Microsoft 页面（如 aka.ms/devicelogin，由系统浏览器打开）输入的账号和密码只发给 Microsoft

Minecraft 官方服务（api.minecraftservices.com）换取 Minecraft 访问令牌，读取游戏档案（UUID、玩家名、皮肤）。登录和刷新时连接XSTS 令牌；之后用 Minecraft 访问令牌读取档案

Mojang 与 Minecraft 下载服务（piston-meta.mojang.com、launchermeta.mojang.com、launcher.mojang.com、piston-data.mojang.com、libraries.minecraft.net、resources.download.minecraft.net）版本清单、游戏本体、依赖库、资源文件、官方 Java 运行时。启动器启动时（本地版本清单超过 10 分钟）、安装版本、启动前补全文件、下载 Java 时连接请求的文件路径（即你选择的版本）；IP 地址；User-Agent CairnLauncher/版本号

Modrinth（api.modrinth.com、cdn.modrinth.com）搜索、查看项目、安装、检查模组更新、导出整合包。都由你的操作触发搜索词和筛选条件（游戏版本、加载器、分类）、项目与版本 ID。安装资源、检查模组更新时，会发送实例中模组文件的 SHA-1 哈希；导出 .mrpack 时还包括资源包和光影包的哈希。不发送文件名和文件内容
CurseForge（api.curseforge.com；无 Key 时用 MCIM）及其文件下载（edge.forgecdn.net、mediafilez.forgecdn.net）搜索和安装。由你的操作触发搜索词、筛选条件、模组与文件 ID；如果你配置了 API Key，则带上该 Key
MC 百科（search.mcmod.cn）查询模组的中文名和简介。只在界面语言为简体中文、在“模组”分类里在线搜索时发生，并且只有内置的离线索引和本地缓存回答不了时才联网；联网时还会对最多 6 个搜索结果的标题继续查询搜索词和搜索结果的标题，使用浏览器式的 User-Agent。结果缓存在本地
LittleSkin 或你填写的外置认证服务器（Yggdrasil / authlib-injector，默认 littleskin.cn）外置登录，以及选择 LittleSkin 作为皮肤来源时查询皮肤。游戏运行时，authlib-injector 会让游戏直接连接该服务器你输入的用户名或邮箱和密码，只发给你选择的服务器；之后用访问令牌刷新。你填写的服务器由其运营者控制，启动器无法验证它是否可信；如果你输入的是 http:// 地址，通信不加密
Hitokoto 一言（v1.hitokoto.cn）每次启动时获取一句语录，在“语录”小组件里点击“刷新”时再获取一次。目前没有单独的关闭开关只有一个普通的 HTTPS 请求，不带账户信息；对方可以看到你的 IP 地址
启动器更新检查（rustcraftmc.github.io、GitHub Releases）检查启动器软件更新（默认启动时静默检查，可在“设置 → 下载与网络”中关闭）以及下载新版本。仅在检测到新版本并由你确认更新时，才会从 GitHub Releases 下载新版本可执行文件请求 update.json 清单文件；下载新版本时请求对应二进制文件；对方能看到你的 IP 地址和 User-Agent。本地校验 SHA-256 哈希，不发送任何账号或本地配置信息
加载器与安装器来源：Forge（maven.minecraftforge.net、files.minecraftforge.net）、NeoForge（maven.neoforged.net）、Fabric（meta.fabricmc.net、maven.fabricmc.net）、Quilt（meta.quiltmc.org）、OptiFine（optifine.net，或经 BMCLAPI）、authlib-injector（经 BMCLAPI，或 authlib-injector.yggdrasil.gservice.top）安装对应的加载器，或首次用外置账户启动游戏时连接请求的文件路径和 IP 地址
你的浏览器启动器在系统默认浏览器里打开的网页，例如登录页面、Minecraft 与 Microsoft 条款、GitHub 链接、MC 百科页面。你点击时才会打开由浏览器处理，适用对应网站的政策

3.2 三类数据的区别

  • 开发者主动收集的数据： 无。
  • 为完成你的请求而发送给第三方服务的数据： 即上表中列出的内容。这些数据是为了登录、下载、搜索等你要求的功能而发送的。
  • 第三方服务自身独立处理的数据： 第三方收到请求之后如何记录、保存和使用（例如访问日志、账户数据），由它们按自己的政策决定。开发者无法控制，也无法代为访问或删除。

3.3 同时适用这些服务的条款

你使用这些服务时，还需要遵守它们各自的服务条款和隐私政策，例如 Microsoft 隐私声明、Microsoft 服务协议 和 Minecraft 最终用户许可协议。开发者不能控制第三方服务的数据处理行为，也不对其负责。

4. 网络通信

4.1 正常的网络行为

  • 你主动登录时，向 Microsoft、Xbox 和 Minecraft 服务发出的 OAuth 与认证请求。
  • 你主动安装、启动游戏或让启动器补全文件时的下载请求。
  • 你搜索模组、安装资源、检查模组更新、导出整合包时，向 Modrinth、CurseForge 等发出的请求。
  • 启动器启动时自动发生的请求：版本清单（本地缓存过期时）、为每个账户加载头像（可能触发皮肤查询）、获取一条语录。
  • 下载时的镜像测速请求。
  • 启动器自身的更新检查与下载：启动器会向项目网站请求静态清单文件（update.json）以比对版本号（启动时可在后台静默检查，可在“设置”中关闭自动检查）。检测到新版本后，仅在你明确确认时才会从 GitHub Releases 下载更新文件，并在通过 SHA-256 校验后完成就地替换。更新检查与下载不包含任何账号或设备标识信息。
  • 本软件没有遥测、使用统计、崩溃上传和广告请求。

4.2 对方能看到什么

收到请求的服务器通常能看到你的 IP 地址、请求的网址和路径、时间、User-Agent（多数请求是 CairnLauncher/版本号，MC 百科请求使用浏览器式的 User-Agent）和 TLS 握手信息。账户令牌只会发往 Microsoft、Xbox、Minecraft 服务，以及你自己选择的外置认证服务器。

默认情况下，本软件直接连接，不使用系统代理，因此上述服务看到的是你的真实 IP 地址。你可以在“设置”的下载页面里让它跟随系统代理。

4.3 这些请求不是数据上报

以上请求都发往第三方服务，用于完成你要求的功能。它们不意味着本软件具有向开发者上报用户数据的功能。游戏进程和模组自己发起的网络连接不在本软件的控制范围内。

5. 数据删除

5.1 移除 Minecraft 账户

在“账户”页面点击账户右侧的删除按钮并确认，该账户的记录和令牌就会从 accounts.dat 中移除。这只删除本机上的副本，已经授予 Microsoft 的授权不会因此撤销。如需撤销授权，请在你的 Microsoft 账户设置中查看并撤销已授权的应用，具体入口以 Microsoft 页面为准。

5.2 清除本地缓存

本软件没有一键清除缓存的按钮。你可以在退出启动器后，手动删除 <数据目录>/cache/、<数据目录>/temp/、<数据目录>/natives/ 和日志 <数据目录>/logs/。它们会在需要时重新生成或重新下载。

5.3 删除配置文件

删除 <数据目录>/config.json 会让设置恢复默认值，同时清除“已同意协议”的记录，下次启动时会重新显示协议和首次使用向导。

5.4 删除数据目录

退出启动器后，删除整个 <数据目录>（默认是可执行文件旁的 .cairn）。其中包括账户、设置、缓存、日志、自动下载的 Java、独立实例与共享资源池（instances/、shared/）、插件及其数据。

5.5 卸载启动器与删除游戏数据是两件事

本软件是便携程序，没有安装程序；“卸载”就是删除可执行文件和数据目录。游戏实例、模组、存档和资源包保存在游戏目录里（默认是可执行文件旁的 .minecraft、%APPDATA%\.minecraft，以及你自己添加的目录），可能与启动器数据目录分开，卸载启动器不一定会自动删除它们；反过来，删除 <数据目录> 也不会删除这些游戏目录。请特别注意：默认的 .minecraft 就在可执行文件旁边，如果你把整个文件夹一起删除，存档也会被删除，请先备份。

5.6 第三方持有的数据

Microsoft、Modrinth、CurseForge、各镜像和皮肤站等第三方保存的数据，需要向它们提出请求。开发者没有你的数据，因此无法替你删除。

6. 数据安全

6.1 账户数据的保护

账户和令牌的保护方式见 2.3。在 Windows 上它依赖 DPAPI；在其他系统上它不是系统凭据库，强度较低。

6.2 令牌的风险与建议

刷新令牌可以在不重新输入密码的情况下续期登录，因此一旦被他人取得，对方可能冒用你的登录状态。建议：使用有密码的系统账户；有条件时开启磁盘加密；不要把 <数据目录> 或 accounts.dat 发给别人；怀疑泄露时，先移除账户，再到 Microsoft 账户设置中撤销授权并修改密码。

6.3 本地文件的访问权限

本软件不单独设置文件访问权限，沿用操作系统对所在文件夹的默认权限（仅在类 Unix 系统上，会把下载的 Java 可执行文件设为可执行）。把启动器放在多人可读的位置（共享文件夹、公共电脑、移动硬盘）时，其他人可能读到明文的 config.json、日志、缓存以及加密的 accounts.dat。

6.4 日志中可能出现的敏感信息

启动器日志 latest.log 写入时不做脱敏。启动器自己写入的内容主要是路径、Java 路径、实例名、版本和错误信息，路径中可能含有你的系统用户名。游戏崩溃时，缓冲的游戏输出会被写入日志。Java 在发生原生崩溃时写入游戏目录的 hs_err_pid*.log，可能包含完整的启动命令行，其中可能有访问令牌；启动器不会改写这些原始文件。

导出的错误报告会遮盖令牌和路径中的用户名，但自动遮盖不保证完整。分享报告之前，请自己检查一遍。

6.5 传输安全

本软件访问上述服务时默认使用 HTTPS。下面两种情况可能使用未加密的传输：一是你手动填写 http:// 开头的地址（外置认证服务器、自定义镜像等），此时账号密码或令牌可能被窃听；二是 Minecraft 游戏档案里记录的皮肤图片地址如果以 http:// 开头，头像图片会按原地址下载，那只是公开的皮肤图片。启动器会检查 Microsoft 设备登录页面的网址是否属于 Microsoft 的域名，否则回退到 https://aka.ms/devicelogin。

6.6 插件与模组

插件是第三方代码，在独立的进程中运行；需要联网、读写任意文件、运行外部程序、修改启动参数等能力时，插件必须声明权限，并由你在启用时确认。其中读写任意文件、运行外部程序和修改启动设置属于高风险权限。模组在游戏进程里运行，开发者无法限制它们的行为。请只安装你信任的插件和模组。

6.7 不承诺绝对安全

没有任何软件能保证绝对安全。开发者采取了上述保护措施，但不能保证它们在所有情况下都有效。

7. 未成年人保护

7.1 本软件的实际情况

本软件在你的设备本地处理数据，开发者不接收也不保存用户的个人信息。本软件不要求你向开发者注册账户，不收集年龄或出生日期，没有设置年龄门槛，也没有内置家长控制或使用时长限制功能。

7.2 第三方账户与服务

登录使用 Microsoft 账户，Microsoft 对未成年人的账户有自己的规则。例如，未成年人的账户需要加入家庭组才能登录，启动器遇到这种情况只会显示 Microsoft 返回的提示。Modrinth、CurseForge 等第三方服务也有各自的年龄和监护人同意要求。

7.3 各地法律

不同地区对未成年人个人信息有不同的规定，例如中国大陆《个人信息保护法》第 31 条和《未成年人保护法》第 72 条（不满 14 周岁的未成年人，处理其个人信息应取得监护人同意）、欧盟 GDPR 第 8 条（面向儿童提供信息社会服务并基于同意处理数据时，各成员国把年龄门槛定在 13 至 16 岁之间）、美国 COPPA（针对收集 13 岁以下儿童个人信息的运营者）。由于开发者不收集个人信息，开发者没有设置单独的监护人同意流程。这些规定在具体情况下是否会对开发者提出要求，见第 8 节。

7.4 给监护人的建议

未成年人应在监护人的指导下使用本软件。监护人可以通过 Microsoft 家庭安全设置和各第三方服务的设置来管理孩子的账户。如果你认为某个第三方服务收集了孩子的信息，请直接联系该服务。

8. 地区法律与用户权利

8.1 如何判断本政策适用的法律

本节根据本软件实际的数据处理方式来说明。本软件的数据在用户设备上本地处理，开发者不收集、不接收用户的个人信息，因此开发者通常没有保存或处理用户个人信息的行为。本节列出各地的主要法律和你的权利，不就这些法律是否适用于开发者作出结论；如果你所在地的法律适用，你的权利应向实际处理你个人信息的一方行使。

8.2 中国大陆

  • 《个人信息保护法》：个人信息处理者是“在个人信息处理活动中自主决定处理目的、处理方式的组织、个人”（第 73 条）。自然人因个人或者家庭事务处理个人信息的，不适用该法（第 72 条）。个人享有知情、决定、查阅、复制、更正、补充、删除等权利（第 44 条至第 50 条），应向处理者行使。开发者不处理你的个人信息，所以没有可供你向开发者行使这些权利的数据；你可以向第三方服务行使。你使用本软件时，设备会直接向境外服务器（如 Microsoft、Mojang）发送请求，开发者不接收这些数据，也不代你向境外提供。
  • 《网络安全法》（2025 年修正，2026 年 1 月 1 日起施行）、《数据安全法》：本软件没有开发者运营的服务端，开发者不收集、不存储用户数据。
  • 《未成年人保护法》《未成年人网络保护条例》：见第 7 节。
  • 不影响你依据《民法典》（包括第 1034 条）享有的个人信息权益。

8.3 欧盟与欧洲经济区

  • GDPR 把“决定个人数据处理目的和方式”的主体称为控制者（第 4 条第 7 项）。开发者没有服务器端的用户数据，也不决定设备上数据的处理，通常不是这些数据的控制者。用户出于纯粹个人或家庭活动处理数据的，GDPR 不适用于该用户（第 2 条第 2 款 c 项）。Microsoft 等第三方服务是它们自己处理数据的控制者。
  • 如果 GDPR 适用，你享有访问、更正、删除、限制处理、反对和数据可携带等权利，并有权向监管机关投诉。这些权利应向相关的控制者行使。
  • 需要说明的是，本软件在某些情况下会在你没有直接操作时，自动向第三方发送你的 IP 地址，例如启动时获取语录、默认启用的镜像（见第 3 节）。这些请求由对应的第三方按其政策处理。

8.4 美国

  • 联邦贸易委员会法第 5 条禁止不公平或欺骗性的做法。本政策只陈述从源代码中可以证实的行为。
  • COPPA：开发者不收集任何个人信息，包括儿童的个人信息。
  • 州级隐私法（加州 CCPA/CPRA，以及弗吉尼亚、科罗拉多、康涅狄格、得克萨斯等州的法律）通常按企业规模、处理的居民人数或出售个人数据的情况确定适用范围。开发者不收集个人信息，也不出售个人信息，不为跨情境行为广告共享个人信息。本政策不假定这些法律都适用于开发者。
  • 如果适用的法律赋予你知情、删除、更正或拒绝出售的权利，由于开发者不持有你的数据，没有可处理的内容；对第三方持有的数据，请向第三方行使。
