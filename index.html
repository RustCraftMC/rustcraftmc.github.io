原生启动器 · Windows 桌面端

Cairn Launcher

纯粹 · 优雅 · 灵动的现代 Minecraft 启动器

用 Rust 原生构建的单文件启动器。启动器本身没有 Chromium 或 JVM；界面由自研的 cairn-ui 图形库绘制，背景模糊和毛玻璃在 GPU 上合成。

  • Rust 原生
  • cairn-ui
  • GPU 毛玻璃
  • 无 JVM 外壳
  • QuickJS 插件

理念

我们相信的事

  1. 01

    原生优先

    能用系统语言直接解决的问题，就不再叠加额外的运行时与外壳。更小的体积、更少的意外。

  2. 02

    隐私为本

    不做遥测，不藏上传。数据留在你的设备上，网络请求直连官方服务或你自己选择的源。

  3. 03

    开源透明

    代码、基准与文档全部公开在 GitHub。每一个性能数字都可以被复现，也欢迎被质疑。
